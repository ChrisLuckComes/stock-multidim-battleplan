## 3. 落地前必须想清楚的五个问题（我的设计风险）

1. **弱势票假信号泛滥**：震荡市里「站上三线 + MA5 向上」几乎人人达标，
   不设附加闸门就是弱势票乱开火。候选闸门：市场状态闸门
   （`gates/market_regime.py` 宽基三态）、`gates/quick_strength.py` 强度快判、
   `regime=continuation`（AGENTS.md：沿线回踩锚短均线时的同款要求）。
2. **「折算量」口径必须先定**：盘中量必须按已过分钟 ÷ 240 折算
   （`ash_live_bar` / `project_session_volume` 同口径），否则缩量误判。
   1.2×20 日均量的分母也要说明是折算前还是折算后。
3. **与 `ma_bull_align` 的分工**：`ma_bull_align` 要求 MA5>MA7>MA10 且
   价>MA20>MA60（日线级）；通道 D 是它的**盘中实时降级版**（只要站上三线，
   不要求完全排列）还是独立判据？两者结论冲突时谁优先，必须先定。
4. **T+1 止损口径**：A股当天买了卖不掉。MA10 止损在盘中可能已破，
   「距 MA5 ≤1×ATR 买入、止损放 MA10」在 T+1 下等于把纠错延到次日 ——
   须按老罗口径给「盘中腿 + 收盘腿」双版本（MEMORY：A股白天可盯盘）。
5. **与 A/B/C 的分工**：D 是沿线（趋势中）通道，与 A/B/C 理论上互补；
   但要防「同一笔行情 A 和 D 同时触发、仓位叠加」。回测须报告
   信号重合率。

## 4. 回测要求（上线门槛）

沿用 `research/backtest_intraday.py` 的六条硬约束（阈值只 import 不复制 /
无未来函数 / entry 两套 / T+1 净账户口径 / 同根先止损 / 信号池先于结果）：

1. 全样本：POOL × 近 60 个交易日，不是 1–4 个手工样本；
2. 对照：单独跑 D，与 A/B/C 并列看净账户%（不是看触发次数）；
3. 重合率：D 与 A/B/C 同日同时触发的比例（>50% = 没有独立存在价值）；
4. 参数敏感性：距 MA5 的 ATR 倍数（0.5/1.0/1.5）、量门槛（1.0/1.2/1.5）、
   MA 组合（5/7/10 vs 5/10/20）；
5. 分市场状态切片：宽基三态下分别的净账户%（弱市泛滥假信号会现形）；
6. 通过线：T+1 净账户 ≥ 0 或不劣于 A/B/C，且弱势切片不出现
   「触发多、全负」形态；否则继续关着。
