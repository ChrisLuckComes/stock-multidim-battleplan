# 六种买法与 T0 规则

## 只做六种买法（强制，由 `rule123.py` 的 `mode` 给出）

研报禁止自拟第七种买法，禁止同时把两种模式写成「现在就买」。读 `evaluate()` 的 `mode` / `priority` / `buy_zone`。

判定顺序：**先看 T0（均线收复+过昨高，出即接管），再看优先 T1，再看次优先 T2，都不成立则 wait。** T1 内部顺序：平台突破 → W底颈线突破 → 旗形下降趋势线突破 → 沿线回踩。**唯一例外（「强上加强」，老罗 2026-09-17 定）**：平台破位但量能不足时，若同时明显沿线主升（贴轨 ≥4 次、收盘在线上 ≤1.0×ATR），两结构互证 → 不拦截，直接按沿线回踩放行，verdict 标「强上加强(平台+沿线主升)」。两种 T2 同时可做时，**大阳后缩量回踩优先于下降趋势线突破**。T1 可做时不执行 T2。已识别旗形时，不用泛化的 `downtrend_tl_break`（走 `flag_tl_break`）。

**量能不再作突破闸门（2026-09-17 用户定：「RVOL 不重要，价格说明一切」）**：
- **下降趋势线家族**（`flag_tl_break` / `downtrend_tl_break`）**完全按价格确认**：收盘站上线 + 收盘落在当日振幅上半区 + 收盘不低于前收（见脚本 `price_conf`）。RVOL 只写进 note（放量=加分项 / 无量=「非放量突破，仓位打折」），**不再一票否决**。理由：这类形态本身就是「缩量收敛 → 突破」，而 20 日均量又被此前的恐慌/暴涨量能污染（ILMN 9/15 RVOL 用均值算 1.70、TEM 9/15 只有 1.03），用 RVOL 卡会系统性漏掉最好的一段。
- **平台 / W底**：同口径改为**价格确认**（脚本 `price_conf` = 收盘落在当日振幅上半区 **且** 不低于前收），排除长上影插针式站上。`RVOL>1.5` 与「宽幅强阳」（实体 ≥1.2×ATR）都**只作加分标注，不再一票否决**：放量/强阳分支给正常仓，价格确认但无量分支给「半仓/试错仓」（verdict 带「·非放量」）。收盘落在下半区或收低于前收 = 插针式站上 → wait（该分支仍保留「强上加强」豁免）。

**★★ T0：均线收复 + 过昨高（2026-09-20 用户定稿，优先级高于 T1 买突破）**

用户自研战法，定级理由原话：「**这一套战法的优先级是 T0，比 T1 买突破还要更高，因为盈亏比最高**」。
与 T1 的本质区别：T1 在**位已破之后**追；T0 在**位未破之前**、均线刚收复、贴着墙蓄势时进场
—— 同一道墙，买点低一截、止损窄一截 ⇒ 盈亏比更高。是「预判买优于顶着买」的同一逻辑，但锚更明确。

**★ 埋伏单是 T1 级入口（2026-09-19 用户定级，实证支撑）**

它不属于上表任何一个「形态」（形态描述**在哪买**，它描述**什么时候把单挂上去**），所以不是新买法；
但**必须单独占用一个 T1 优先级**，因为它与当日 `mode` **并列争夺「先成交者」**：

- 当日 `mode` 的买点若在现价**上方**（突破/追高类），而埋伏单在**下方** → **埋伏单先触发**，它才是实际首选。
  引擎已加 `pre_breakout.beats_current_mode = true` 显式标出这种关系。
- 反过来（买点在下方 = 回踩类），两者不冲突，埋伏单只是「提前在突破位挂了张单」。
- 实测赛分 688758（`_sf_915*.py`）：9-14 `downtrend_tl_break`（T2）+ 埋伏单 28.97；
  9-15 主板 `mode=wait`（大阳后未满 3 根）**当日无买点，只有埋伏单**；9-15 高 29.02 ≥ 28.97 成交 → 至 9-18 收 **+13.22%**。
  **若只等 `mode` 信号，9-15~9-18 那 15.9% 整段踏空。**
- 同预算下：埋伏 28.97 / 风险 3.62% vs 当日顶着买 28.30 / 风险 5.41%
  → **1R 效率 1.46 倍**（买价还贵 2.37%，靠止损更窄赢回来）。
- 字段：`setup_kind="pre_breakout"` / `tier="T1"` / `priority=1` / `role="primary_entry"` /
  可选 `beats_current_mode`。扫描器渲染时**与 T1 同档展示，但须单独一行**，不可被当日 T2 的买点盖掉。

**买区口径（全库统一）**：买区自**防守位 / 突破位单边向上**，带宽 **1.0×ATR**，下沿不低于该位——突破类用突破位，沿线回踩用被回踩的那条线，大阳后缩量回踩用大阳低点 / 缺口下沿。突破模式的定义就是「收盘站上突破位」，在尚未突破的价位挂买单自相矛盾；这同时保证硬止损恒落在买区下沿之下。**跳空例外**：基准上移到**缺口上沿（= 突破根低点 / 大阳低点）**，整段买区不得落进缺口（另见第 5 节「大阳后缩量回踩」）。

**买区不变式（2026-09-16）**：`buy_zone` 带下单带（`primary_lo`/`primary_hi` 非空）**当且仅当**该 verdict 确实给出了可挂单价位。以下情形**一律空区**（`primary_lo`/`primary_hi` = `None`）：
- 大阳后收盘跌破防守位（`broke_yang_low`，`invalid=True`）
- 站上突破位但**价格未确认**（收盘落在当日振幅下半区，或收低于前收 = 上影插针式站上）→ 空区 + verdict「·价格未确认」，note 写明「不算突破」。**量能不足本身不再是空区理由**（平台/W底同此口径）
- 「未形成平台/W底/旗形突破、沿线回踩、大阳后缩量回踩或下降趋势线突破」的兜底 `wait`（结构不成立）

理由：这些分支原先不传 `buy_zone`，`pack()` 便回退到 `bz_line`（活平台沿线位），打印出一个 2×ATR 宽的区间。区间摆在「买区」列、而 verdict 写着「作废 / 不买 / 未形成」——**这是「看到买区、其实没有买点」的误判源**。活平台沿的位置由报表「活平台/R1」列独立承载，不靠 `buy_zone`。有值即代表有挂单价位，这条不变式必须守住。

**可执行闸门（突破类，三档）**——「买区位」与「能不能执行」是两件事，不得用前者卡死后者：

| 现价距突破位 | `recommend` | 含义 |
|---|---|---|
| ≤1.0×ATR（买区内） | `True` | 可执行 |
| 1.0–2.0×ATR（已出买区上沿） | `True` | **仍可执行，但只能挂回踩单（上沿一带），禁止市价追**；`buy_zone.chase_only=True`，报表标「≥上沿·只挂单」 |
| >2.0×ATR | `False` | 不追，`mode=wait`、verdict「突破已延伸·等回踩」 |

即：出买区不等于不能买，只等于不能市价追。唯一的不追线是「不追高」那条——**离买位 >2×ATR 不买**。

**盘中口径（`intraday=true`，2026-09-17 INTC 案例）**

美股日线源盘中**不返回当日半根**。旧实现只把实时价存进 `spot_quote`，结构仍按昨收算，于是**突破当天引擎看不见突破**：INTC 9/17 已站上平台沿 107.57（现价 110.7），输出的 `mode` 却是昨收口径的 `line_pullback`，买区 99.45~104.03 整段落在突破位之下 —— 用户实况：「突破了平台，却让我 104.03 买」。更糟的是三条盘中通道也都判「过期/不给信号」，**输出只剩「等回踩」，而价格一路不回**。

现改为：`session=Open` 时用 Yahoo 5 分钟线合成今日未收盘 bar 并入结构（`merge_intraday_bar`）。判定要点：

- `mode` / `buy_zone` / `days_above_platform` **一律按盘中刷新后的结构读**，不是昨收口径。突破位一旦被站上，买区基准立刻从回踩线抬到突破位（INTC：104.03 → 107.57）。
- 但**决策点仍看尾盘**：输出带 `confirm_at`（北京时间 03:45–04:00 / ET 15:45–16:00）。盘中价非收盘价，收盘仍成立才动手 —— 这是执行纪律，**不是「不做」**。区别在于：买区已随突破上移且现价在区内，读数是「可执行、待尾盘确认」，而不是「只能等回踩」。
- **盘前 / 盘后不合成**：成交稀疏，盘前价越过平台沿不能当「收盘站上」。`session=Closed` 时日线本身完整，也不合成。
- 合成 bar 的 `v` 是**量比口径**（累计量按已走时段折算成预计全日量），`v_raw` 才是累计量。不折算就会把放量突破误标成「非放量」而错压仓位（INTC 12:27 ET：累计 85.5M 直读 RVOL=0.94 → 折算后 2.07 = 放量）。
- A 股不受影响：东财日线盘中同样不返当日半根，`merge_intraday_bar` 直接不合成，A 股走 `in_ash_session` + 盘中三通道。

**预备突破单（`pre_breakout`，2026-09-17 SDGR / TEM / ILMN 案例）**

未突破 ≠ 没有单可挂。`evaluate()` 除当日 `mode` 外**额外**输出 `pre_breakout`。两种挂法，同时够格时取**距价更近**的那个：

**① 水平平台版**（`platform_from` = 平台成形日）：`platform.kind ∈ {pressing, near, broken}`（价格顶在活平台沿下方 / 刚贴近 / 刚站上但未确认）且距沿 ≤1.2×ATR、非极度缩量（RVOL≥0.8）、非下跌段且收盘站上 MA20。字段：`order` / `level` / `trigger` / `hard_stop` / `risk_per_share` / `dist_atr` / `platform_from` / `cushion_note`。

> **2026-09-19 起放宽**：原闸门只认 `pressing`，导致「方向已明但价格还没贴到沿」的日子**无单可挂** → 只能等次日顶着买。实证见下节《★ 预判买 vs 顶着买》，故放宽到 `near`/`broken`。

**② 下移斜线版**（`anchor=down_tl`，2026-09-17 ILMN / TEM 案例，即「画斜线突破下降趋势线」的可执行形式）：价格贴在**下降趋势线**下方、收盘距线 ≤1.2×ATR 且 `regime≠downtrend` 时，在**线上方**挂 buy-stop。字段：`order` / `anchor` / `level` / `trigger` / `hard_stop` / `risk_per_share` / `dist_atr` / `line_from`。
- 触发价取**下一根**的线值 +0.05×ATR：线在下移，用当日线值会把单子挂高。
- 止损 = 线下 **1.0×ATR**（平台版是 0.5×ATR）：ILMN 20 笔样本显示贴沿 0.55×ATR 的止损有 **94% 在 10 日内被扫后又涨回**（错杀），1.0×ATR 才是期望最优。
- 实测：ILMN 9/11 挂 210.13 → 9/15 成交（当日开盘 208.95 直接跳过整条旗面线）→ 至 9/17 收 245.21 = **+16.7%**；TEM 9/10 挂 62.92、9/11 挂 62.18 → 9/14–15 成交 → 至 9/17 = **+26.4% / +27.9%**。

- 它是**独立于当日 `mode` 的 T1 级入口**（不是第七种买法：形态说的是「在哪买」，它说的是「何时挂单」），
  与当日买点**并存、先到先做**，不改变 `mode` / `recommend`。**优先级与 T1 同级**，且当买点在上方、
  埋伏单在下方时（`beats_current_mode=true`）**它就是首选**。详见本节末尾「埋伏单是 T1 级入口」。
- **`triggered` / `status`（2026-09-17 INTC 起）**：盘中口径下，脚本拿**昨收口径**算出的那张埋伏单，去比今日合成 bar 的最高价。越过触发价 → `triggered=true`、给 `fill_px`（跳空则按开盘价成交），`verdict` 前置「**命中预案单 X**」，note 写明「已成交，不再回头等回踩」；未越过则 `triggered=false` 并写明「继续挂着」。**这一条专治「明明挂单成交了、输出还在喊等回踩」**：TEM 9/17 命中 73.18、ILMN 命中 233.85、INTC 命中 106.68，都是当日实际成交的埋伏单。
- 挂法：次日开盘前，在平台沿**上方** `trigger`（= 沿 +0.05×ATR）挂 **buy-stop**（停损买单）；触发即突破确认。
- 止损 = max（平台沿 −0.5×ATR，MA5 −0.10×ATR）；跌回平台沿下方 = 假突破，次日盘中破即走。
- **为何必须有**：SDGR 2026-09-14 活平台沿 21.40 距收盘仅 0.64×ATR，当日却只输出「大阳回踩 18.84–19.86」——该回踩从未发生（9/15 最低 20.34），次日跳空越过买区，整段错过。按本单 21.45 成交 → 至今 **+29.9%**。
- 回测（SDGR 近 13 个月）：10 笔独立挂单成交 6 笔，平均止损仅 **−2.82%**，固定持有 5/10/20 日 **+3.06% / +3.45% / +5.24%**；同期原回踩逻辑有 **3/10 笔在 5 个交易日内完全没成交**。
- 立论：买点是**突破位本身**，不属追高；buy-stop 需触发才成交、假突破自动不成交，故与「不追高」闸门不冲突。
- 注意：**反转初期 `c2` 必为 False**（SDGR 9/14 即如此），故本单的结构守卫用 `regime + MA20`，不得改用 `c2`——否则会把要覆盖的场景整个挡掉。

**强突破例外（`buy_zone.next_day_chase`，2026-09-17 SDGR 案例）**

`chase_only=True`（现价出买区上沿 1–2×ATR）时，若 **RVOL ≥ 2.5**（强突破），次日往往**不给回踩**：SDGR 9/15 RVOL=3.85，次日 23.29 直接跳空越过回踩单 22.59，之后再未回落 —— 只挂回踩单等于整段吃不到。故此时在 `buy_zone` 内额外输出 `next_day_chase`：

| 字段 | 值 | 说明 |
|---|---|---|
| `limit` | 突破位 + 2.0×ATR | **与「不追高」同一条线，不越线** |
| `size_ratio` | 0.5 | 半仓——追入风险更大，用仓位对冲 |
| `stop` | 突破阳 (H+L)/2 | 比结构止损紧，收紧风险敞口 |
| `valid_for` | 仅次日 | 不成交即作废，不延长 |

- 执行：次日开盘后 **≤ `limit`** 才可限价买入；超 `limit` 不追。
- SDGR 实测：9/16 开 23.29 ≤ 23.78 → 成交，止损 22.02，至今 **+19.62%**。
- 大样本（SDGR，收盘创 20 日新高 + 次日开盘买入，n=8）：RVOL≥2.5 组 3 次，5/10/20 日 **+4.58% / +7.78% / +6.84%**，短期优于 1.5≤RVOL<2.5 组（+0.36% / +2.22%）。**但仅 3 次样本，方向一致、不足以当主力——它是次优保底，不是首选路径。**
- 与预备突破单的分工：**能提前埋伏就埋伏（买在突破位，最优）**；没埋伏上、且突破日 RVOL≥2.5 或宽幅强阳，才启用本条（买在延伸位，次优、半仓）。

### 1. 平台突破（优先 T1）

横盘/箱体/前高被收盘打穿。买的是**突破位本身**，不是均线。

- 触发：近 **3 根内**收盘才站上**活平台沿**（脚本字段 `platform`），且**价格确认成立**（收盘落在当日振幅上半区 **且** 不低于前收）。尾盘/盘后确认即买。`R1` 仍是 123 的 P0–P1 反应高，**T1 用 `platform` 不用已死的旧 R1**。刚突破后近 3 根，沿仍是被破的那条，不是突破阳的最高价。
- 已站上超过 3 根 = 突破已结束，改判沿线回踩、大阳后缩量回踩或 wait，**不再标平台突破**。
- **量能不再一票否决（2026-09-17 用户定：价格说明一切）**：`RVOL>1.5` 或宽幅强阳 → 正常仓，note 标「放量确认」；价格已确认但量能未放 → 仍给买区，verdict 标「平台突破(优先T1)·非放量」、note 写「半仓/试错仓，次日不破当日低点再加」。（ILMN 9/17 正是此类：收盘 245.21 站上平台沿、价格确认，此前因「量能不足」被判 wait 而踏空。）
- **价格未确认**（收盘落在当日振幅下半区 / 收低于前收 = 上影插针式站上）：wait，不算突破。**例外（强上加强）**：同时贴轨沿线主升（触及 ≥4 次、收盘在线上 ≤1.0×ATR）→ 两结构互证，按沿线回踩放行，verdict「强上加强(平台+沿线主升)」；收盘已跌破该线则不豁免，仍 wait。
- 布林上轨：贴轨走 + 带宽扩张 = 趋势，可当突破确认；单日爆量刺穿次回内侧 = 派发，不追。
- 123 三项全过（破下降趋势线 + 未创新低 + 过前高）= 本模式的加强版，仍标 `platform_break`（优先 T1），备注下降趋势线已破。

### 2. W底颈线突破（优先 T1）

双底（近似等深摆动低）后，收盘站上两底之间的反弹高（颈线）。买的是**颈线突破**，不是均线。

- 触发：脚本识别 `w_bottom`（左底/右底/颈线），近 **3 根内**收盘才站上颈线，且**价格确认成立**（收盘在当日振幅上半区 + 不低于前收）。
- 结构止损看颈线下；硬止损锚优先突破阳下沿或长阳中点，再下 0.10×ATR gap。
- **价格未确认**（收盘落在下半区 / 收低于前收 = 插针式站上）：wait，verdict「W底颈线突破·价格未确认」。**量能不足不再是 wait 理由**（同平台突破，量能只写进 note）。已站上超过 3 根不再标本模式。
- 与平台突破同时可做时，平台突破优先。

### 3. 旗形下降趋势线突破（优先 T1）

主升之后的**旗形整理**：先有短促旗杆大涨，再有下降高点连成的旗面；收盘站上旗面下降趋势线即买。

- 触发：脚本识别 `bull_flag`（旗杆 + 旗面下降趋势线），近 **3 根内**收盘才站上该线，且**价格确认成立**（收盘在当日振幅上半区 + 不低于前收）。**量能只写进 note，不作闸门**（放量=加分项；无量=「非放量突破，仓位打折」）—— 2026-09-17 用户定：RVOL 不重要，价格说明一切。
- 旗面线若已离价 >2×ATR（形态过陡 / stale），评估时会落到下降趋势线（T2）处理，不会因「存在旗形」硬撑一个不可执行的买区。
- 结构止损看旗面趋势线下。这是升势里的整理突破，标优先 T1，不用泛化的 T2 下降趋势线突破。
- 已识别旗形时，**禁止再标 `downtrend_tl_break`**（脚本 `test_flag_blocks_generic_dtl` 守住此规则）。
- ⚠️ 旗面下降线的锚点取**近端局部高点**（`detect_down_trendline`），不用 `pivots(w=3)`：单调下移段内 w=3 根本不产生枢轴高（TEM 8/27 高 71.89 因左侧 8/24 高 72.02 更高而被丢弃），会取不到锚点。旧实现的「旗杆后右半段最高点」近似也有致命 bug —— 突破那根自己会成为右半段最高点，线被拖到突破价、`days_above_tl` 归零，**形态在突破当天自我消失**（TEM 9/15：9/14 线 62.18 正确，9/15 变成 68.94）。

**旗形 / 平台 / 下降通道 三分判据（2026-09-17 CRSP 案例）** —— 同样是「涨一段 → 整理 → 再突破」，先看整理段的**几何形状**再定归类：

| 整理段特征 | 归类 | 优先级 | 突破位 |
|---|---|---|---|
| 高点**逐级下移**（斜线），且**回撤 ≤2/3 旗杆** | 旗形 `flag_tl_break` | T1 | 旗面下降线 |
| 高点**基本水平**（不下移），收盘站上活平台沿 | 平台 `platform_break` | T1 | 水平沿 |
| 高点下移但**回撤 >2/3 旗杆** | 只算**下降通道 / 斜线** → `downtrend_tl_break` | T2 | 那条斜线 |

- **回撤深度是「旗形」与「通道」的分水岭**：脚本 `detect_bull_flag` 的硬闸门是「回撤 > 0.66×旗杆高 → 不是旗形」。旗面要的是**浅回撤的紧凑整理**（约 1/3~1/2）；回吐超过 2/3 说明抛压已把旗杆吃掉，属深度回调。
- **CRSP（2026-09-17）是「引擎正确拒绝旗形」的案例**（与 TEM/ILMN 的**误拒**相反，那两个是检测器 bug、已修）：脉冲 7/28@45.89 → 8/21@62.53（+36.3%），整理段最低 9/14@51.33。
  - 按整段脉冲算回撤 **67.3%**（超 66% 上限）；按脚本选出的 12 根旗杆（51.51→62.53）算回撤 **101.6%** —— **旗面最低直接跌破了旗杆起点**，形态上根本不是旗。
  - 整理段高点 62.53 → 58.96 → 53.80 **逐级下移**，没有水平沿 → 也不是平台。
  - 故归 `downtrend_tl_break`（T2）。2026-09-17 引擎给的正是「破斜线 2.33×ATR → 突破已延伸·等回踩」。
- **头顶旧高是第二重判据**：CRSP 上方还压着 8/21 高 **62.53** 与 7 月中旧高 **63.45**（`living_platform` 报 `kind=pressing`、`days_above=0`）= **平台压迫但未突破**。这与 TEM/ILMN 突破后**创新高、上方无套牢盘**是完全相反的位置 —— 同样是 +11% 大阳，前者的上方是**供给**，后者的上方是**真空**。评估时必须把「水平高破了没有」单独说清，别只看斜线。
  → 推论：CRSP 若后续**收盘站上 62.53~63.45**，即转入 `platform_break`（T1，且是创新高）；在那之前按 T2 试错仓对待。

### 4. 沿线回踩（优先 T1）

已经在主升里，沿着某条**肉眼可见的线**上升，买回踩**这条线**的点，不追离线过远的价格。

- **默认画线**：用最近两个上升摆动低点 P0→P1 连线，外推到今日，得到买区。这就是「沿趋势线主升」的线。脚本 `buy_zone.anchor=hl_trendline`。
- **加速线豁免（2026-09-18 老罗指出 BE 实例）**：斜率 **>0.25×ATR/根** 的 P0→P1 线视为**加速轨迹线，不是支撑线** —— 它每天自行抬升的幅度已接近标的正常日波动，外推时必然「追上」价格，只要横盘一两根就自动变「跌破」，与价格是否真的走弱无关。此时**该线既不作回踩锚、也不作否决依据**，改由均线锚接手（`rule123.tl_slope_atr()` 计算，阈值 `TL_SLOPE_MAX_ATR`）。
  - BE 2026-09-18：P0=9/1 低 197.50 → P1=9/14 低 249.05，斜率 **6.44 元/根 = 0.341×ATR/天**（实测 34 只样本第 **94** 百分位；50% 分位 0.008 / 75% 0.088 / 90% 0.242）。外推到当日 = 274.83，而**按昨线 268.38 看价格 269.64 仍在线上方** —— 外推一天就翻转了「是否跌破」的结论。当日「跌破」的 5.19 元里，**6.44 元是线自己涨上去的**。
  - 同一豁免也适用于第 5 节「大阳后缩量回踩」的升势过滤（`still_uptrend`）：加速线不作否决，升势只由 P1 与 `c2` 把关。
  - 实测影响面：34 只样本仅 2 只锚变更（BE → `ma5`；山东黄金 600547 斜率 0.258 → `ema10`）。
- **例外（很明显贴着某条均线走）**：近 8 根至少 4 次低点贴着 EMA10 / MA5 / SMA20，当 P0→P1 上升趋势线不可用（加速线豁免或 P0/P1 点数不足）时，才以该均线兜底。趋势线可用时优先趋势线。禁止用 VWAP、禁止「谁 tag 多谁上」把均线/VWAP 选成默认买区。
  - ★ **兜底容差必须是相对百分比，不能是 0.5×ATR 绝对值**（2026-09-21 锐捷 301165 伪贴线）：旧实现按「低点距均线 ≤0.5×ATR」判触线，ATR 被前段暴涨撑大时该容差可达 **3.2%**（本票 0.5×ATR = 3.69 元），于是**下跌段里破线 2~3% 也被算作「触及」** → 把「跌穿均线」误标成「沿均线回踩」。用 output-pitfalls #21 的 ±1%/±2%/±3% 复核：锐捷近 8 根 **±1% 命中 0/8**，且 MA5 近 12 根**下移**（118.88 → 113.78，−0.063×ATR/根）—— 那是「均线在追赶价格」，根本不是贴线。
  - ⇒ **判据收紧**：真贴线须 ±1% 有 **≥2/8** 命中，**且均线方向不为负**；兜底容差改用相对百分比（建议 ≤1.5%）。ATR 只用于仓位与止损宽度，**不用于贴线判定**。不满足时本模式不成立 —— 只能定性为「强势整理，可低吸」，不得当趋势回踩给 T1 仓位。
- **短均线锚趋势闸门（2026-09-17）**：锚为 `ma5` / `ema10` / `sma20` 时，还必须 `regime=continuation` **或** 收盘 > SMA20，否则模式可标沿线回踩但 **`recommend=False`**（note 写「短均线锚·趋势偏弱」）。弱票阴跌/横盘也会反复蹭 MA5，肉眼是下跌趋势却被当成 T1——反例科华数据 002335。`hl_trendline` 不受此限。强上加强豁免同样要过此闸。
- 触发：结构完好（收盘>P1 且自 P1 未创新低）+ 现价距该线 **≤1×ATR** + 缩量尾盘。结构止损 = 收盘破**所回踩的那条线本身**（贴轨时用那条已选均线 EMA10/SMA20/MA5；2026-09-18 起不再统一换成 MA5 —— 见第 6 节「铁律零」）。入场写死。
- 距该线 **>2×ATR** 或 1–2×ATR 未到位：本模式不买，**让给 T2**（看大阳后缩量回踩或下降趋势线突破）；两者都没有才写「等回踩该线」。
- 画不出上升趋势线（P1 不高于 P0）且也没有明显贴轨：不编造买区。

### 5. 大阳后缩量回踩（次优先 T2）

已经在上升趋势里，但还没回到那条上升线。买的是**大阳线之后的缩量回踩**，不是回踩上升趋势线。上升趋势线在此模式里只过滤「还在不在升势」。

- **升势过滤（两条通道，任一成立即放行）**：
  - **常规**：P0→P1 低点连线，收盘仍在该线之上（且未破 P1）。
  - **反转放量修复**（放宽档，2026-09-16 起）：强势票最常见的启动形态是「先破位洗盘 → 一根放量大阳收复 P1」，此时 `c2=False`（自 P1 曾创新低）却已站上 P1。原门控会把这种**真信号整段丢弃**（ILMN 9/15：+6.76%、量 1.70 倍、收 222.29 站上 P1 206.82，却只给 `wait` 且买区为空）。放宽后四条**必须同时**成立：① 收盘站上 P1；② 大阳量 ≥ 其前 20 日均量 ×1.5；③ 大阳实体 ≥1.2×ATR **或** 涨幅 ≥4%；④ 现价未回吐到大阳体下半部。任一不满足即退回常规通道，宁缺勿滥。
  - 放宽放行时输出 `buy_zone.gate="reversal_yang"`、`relaxed=True`，note 前置「【反转态·放量大阳·已放宽】」——**报告里必须显式标注**：这类买点建立在「破位后修复」之上，比常规升势回踩脆，仓位按试错仓走，破防守位不得再看一天。
- **找最近一根大阳线**（近 10 根内）：实体阳、收在上沿，实体或振幅够大（约 ≥0.8×ATR 或涨幅 ≥3%）。一字涨停也算（实体为 0，但相对前收跳空）。
- **大阳当日不追**。后面缩量回踩，同时满足：量缩到**这波调整里的近期最低**（允许约 10% 容差，且低于大阳当日量）；**最近 3 根不再创新低**（每一根低点都不下破此前回调低点，允许 0.1×ATR 噪声）。后者优先：说明主力还在控盘，不是自由落体。比急杀再走 N 字更强。未满 3 根或近 3 根仍在创新低 = 不买。
- 不要用「大阳量的 70%」那种比例。
- **买区（下单带）的统一口径**：贴防守位（大阳低点 / 缺口下沿）**单边向上 1.0×ATR**，与突破类买区同构。**大阳体「低点~高点」是「未走坏的有效性边界」，不是买区**——它常宽达 2~2.5×ATR，落在这样的区间里等于没有价位：挂在区间下沿和挂在上沿是两笔完全不同的交易，无法执行。判断「是否还在调整区」用大阳体，「挂在哪个价」用买区，两件事分开。
- **普通大阳（有真实日内振幅）**：买区 = **大阳低点 ~ 大阳低点+1.0×ATR**。防守 = **大阳低点**。收盘跌破大阳低点 = 作废。
- **跳空高开、但大阳有实体/光脚**（开盘远高于前收，低点≈开盘，如石头 8/25 开 125 收 135、前收 112.5）：缺口在大阳低点下方。买的是**缺口上沿 = 大阳低点**一带（买区 = 大阳低点 ~ +1.0×ATR），**不买回补缺口**。防守仍是大阳低点；跌进缺口 = 破防守。
- **一字板 / 振幅极小的跳空**（当天几乎没有低点，板价不能当防守）：买区 = 回踩缺口，取 **前收 ~ min(板价, 前收+1.0×ATR)**。防守 = **缺口下沿（前收）**。收盘跌破前收 = 缺口回补失败，作废。不要把涨停价/一字价写成止损。
- 大阳后继续创新高延伸、没回到买区 = 不追。量没缩到近期最低、或近 3 根仍在创新低 = 不买。
- **「回到买区」= 回到上面那个 1.0×ATR 的下单带，不是「回到大阳体内」。** 回踩到大阳中部 / 上半部不算到位，仍属「等回调整区」。
- T1 沿线回踩已经贴线可做时，不执行本模式。

### 6. 下降趋势线突破（次优先 T2）

下跌段里、**没有可识别旗杆**时，收盘站上**下降**的高点连线。买趋势线突破位。这是反转里较早、也较容易失败的一档，所以是 T2：仓位用试错仓，目标先看到前高/平台沿；过了前高则升级为平台突破（T1）。

- 触发：**下降趋势线（斜线）**近 **3 根内**才被收盘站上，且**价格确认成立**（收盘在振幅上半区 + 不低于前收）。量能只写进 note，不作闸门。
- **线的画法（2026-09-17 修）**：取**近端局部高点**中「依次下移」的那条，按「被最多触碰、被最少收盘穿越」评分选出（`detect_down_trendline`）。**不得用「P1 之前两个枢轴高」** —— TEM 2026-09 那样会取到 8/12@57.03 与 8/21@72.96（一条**上升**线）并外推到 97.99→111.65（当期价格仅 60-70），`declining=False`，本模式永不触发，连 123 的条件1（站上下降趋势线）也永远为 False。
- 未破线：不抄底。**但若价格已贴到线下 ≤1.2×ATR，并给出 `pre_breakout`（`anchor=down_tl`）的 buy-stop 埋伏单 —— 那才是本形态的首选入口**（买在突破位，不追高）。
- 已破线超过 3 根、又还没过平台：不追趋势线，等平台突破或等回踩。
- 与 T1 同时成立时，执行 T1，本模式只作备注。
- 已识别 `bull_flag`：改走旗形突破（T1），本模式不标。
