# 三板组（接力资金）识别与避雷

> 出口脚本：`gates/first_board_money.py`（SKILL.md 规则 24）。本文件放**口径与依据**，SKILL.md 只放可执行判据。
> 老罗 2026-10-08 提供操作手册，2026-10-08 落地。

---

## 1. 三板组是什么

同一批资金用**多个关联账户**接力做一只小盘票：首板建仓 → 二板诱多 → 三板出货。
钱的性质是**接力钱**，不是投资钱：

- 他们的利润来自「后面有人以更高价接」，不来自公司价值；
- **第三板是固定的出货日**（撤封单、反手万手砸跌停）；
- 出完之后 A 字杀，跌回起点。

⇒ 判的是**钱的性质**，不是票好不好。判据要落在**盘口与席位证据**上，不落在市值/价格猜测上。

## 2. 全周期手法（老罗手册）

| 阶段 | 手法 | 可观测特征 |
|---|---|---|
| **选股** | 微盘 +「三无」 | 流通 5~30 亿；**无机构持仓、无明显利好、板块冷无跟风** |
| **首板 · 建仓** | 一线天 / 厂字形 | 早盘直线拉升、中间**几乎无回调**；封板后买一挂**巨量封单**（甚至超过流通盘的合理比例）⇒ 假单 / 拆单制造稀缺，散户**根本排不进** |
| **二板 · 诱多** | 缩量一字 / T 字 | 全天成交极少 ⇒ 逼你在竞价或开盘挂单，买不到就追高 |
| **三板 · 屠杀** | 撤封单反手砸 | 高开低走 / 天地板 / 断头铡刀；多在 **9:30–10:30 或下午开盘**万手砸跌停；之后 A 字杀 |

### 龙虎榜「死亡席位」
**联储证券宁波分公司 · 华源证券深圳分公司 · 天风证券江阴人民东路 · 华鑫证券（特定营业部）**。
⚑ **买入前五出现 ≥2 家关联席位且金额相近 = 自导自演**（对倒）。

### 盘口两个反常
1. **封单远超流通盘** —— 如流通 10 亿、封单 3~4 亿（30~40%），极不正常；
2. **封单全天纹丝不动**（不自然），或**整点整齐撤单**（程序化挂撤）。

### 量能节奏
**首板放量（建仓）→ 二三板缩量（锁仓）→ 出货板巨量（砸盘）**。
⇒ 单看「首板放量」不能定性（真抢筹也放量），要看**节奏变化**：二板该放不放（缩量一字）、出货板突然巨量，才是指纹。

## 3. 应对规则（老罗三原则）

1. **决不碰**「流通 <40 亿 **+ 无业绩支撑 + 无厘头冷门**」—— 三条**并列**，缺一条都不足以单独成立（微盘 ≠ 三板组）。
2. 已持有且怀疑是三板组 ⇒ **第二 / 第三板开盘坚决止盈**，不等第四板。
3. **不接一字飞刀**：缩量一字**持有者**不必因缩量而卖（还没出），但**买入者**排不进；
   **炸板放量必死** ⇒ 炸板就走，不博回封。特别不接**无逻辑一字涨停**与「强势封板营造假象」的小盘股。

## 4. ⚑⚑ 为什么不用「流通市值 / 股价」当门槛（实证）

初版门槛写的是「首板 + 流通 ≤100 亿 + 股价 ≤20 元 ⇒ A 高危」。
老罗 2026-10-08：「**这判断也太武断了**」⇒ 已作废。实证 `research_first_board_size_2026-10-08.py`：

**样本**：2026-09-09 ~ 09-30 共 15 个交易日的**首板**票，n = 611。
**结果变量**均不含本脚本的构造打分（避免循环论证）。

| 口径 | 流通市值 Q1→Q5 | 股价 Q1→Q5 |
|---|---|---|
| 次日**连板率** | 22.0% → 7.4%（**z=3.22, p=0.001**） | 19.5% → 9.8%（**p=0.032**） |
| 次日收盘买入**后 3 日收益** | −1.02 / −0.93 / −1.92 / −0.05 / −1.41 | **−3.32%（胜率 23.8%）** → +0.87% |

**三点结论**：
1. 统计关系**确实存在且方向一致**（小盘低价更容易连板、低价组收益最差）；
2. 但**市值那组按收益完全不单调**（Q4 最好 −0.05%、Q3 最差 −1.92%）⇒ 二元阈值把 Q1~Q4 混成一档，跨度巨大，**阈值站不住**；
3. 最根本：它证明的是「小盘低价**更容易被接力**」，**不是「更危险」**。
   对打板者，连板率高是**机会**；危险发生在**第三板之后**。
   ⇒ 把「小盘低价」标成高危 = **用法错误**。

**现行处理**：规模只作**连续读数**（流通 X 亿 / 股价 X 元）打印，不设阈值、不分档；
打分里只保留 `流通 ≤30 亿 +1 / ≥100 亿 −1` 的小权重项，且文本强制注明
「**单独不构成避雷理由，须配无业绩 + 无逻辑 + 无板块**」。

## 5. 脚本口径（`gates/first_board_money.py`）

### 触发门槛
**只有一条：当日收盘涨停。** 未涨停 ⇒ 打印「不适用 · 跳过」、不给结论；`--json` 输出 `applicable:false`。
理由：脚本靠涨停价判「封板」，非涨停票会把**当日分时最高价冒充涨停价** ⇒ 假结论
（大金 002487 09-30 +7.83%、涨停价 47.22，被正确拦下）。`--force` 可绕过（复盘用）。

### 打分项（正分越高越像三板组）

| 项 | 判据 | 分 |
|---|---|---|
| **连板阶段** | ≥3 板（出货日）／2 板缩量一字（板上时间占比 ≥80% 且密度<1.5） | +3 / +2 |
| **封单 ÷ 流通市值** | ≥20%（假单）／≥10%／≥5% | +3 / +2 / +1 |
| **一线天** | 拉升段最大回撤 ≤2%／≤4% | +2 / +1 |
| 封板时点 | 14:30 后（尾板）／13:00 后 | +2 / +1 |
| **封板后量密度** | >2（出货换手）／<0.6 且封单/流通 ≥10%（假封单无成交） | +2 / +2 |
| 量倍数 | >5（爆量建仓）／<2（温和不放量） | +1 / −1 |
| 换手率 | >15%／<2% | +1 / −1 |
| **板块效应** | 同行业涨停 ≤1 只（孤板）／≥3 只 | +1 / −1 |
| 流通市值 | ≤30 亿（微盘）／≥100 亿 | +1 / −1 |
| **席位** | 死亡席位命中／其他游资营业部关键词 | +3 / +2 |

**封板后量密度 = 板上成交量占比 ÷ 板上时间占比**：>1 板上放量换手（分歧/出货），<1 缩量。
⚑ **旧口径「密度 <0.6 = 缩量锁仓 = 惜售最强 −2」已废** —— 缩量既可能是真锁仓，也可能是
**假封单没人真成交**；现在只在**同时封单/流通 ≥10%** 时才判「巨量假封单 + 板上无成交」。

### 结论覆盖层（与打分无关，不被负项抵消）
- **已 ≥3 连板 ⇒ 至少判「游资接力型（三板出货窗口）/ 高」**，action 强制写「第三板=出货日，不接力；已持有 ⇒ 开盘坚决止盈，不等第四板」。
  （否则 +3 会被「封单厚 −1 / 板块 −1 / 量温和 −1」抵消掉，600241 时代万恒 3 连板曾被抵消成「混合型」）
- **二板且非高危** ⇒ 追加「缩量一字排不进，**不接一字飞刀**；炸板放量必死」。

### 分档
≤−3 机构/锁仓型 ／ −2~1 混合型 ／ 2~4 游资接力型 ／ **≥5 三板组高危**。
≥5 属**标的级证据**，够格否决该票参与（含回踩档），但不波及其他票、不缩放全仓。

## 6. 已知边界

- 龙虎榜**只取当日偏离值前三**，未上榜是常态 ⇒ **未上榜 ≠ 无游资**，必须靠分时/量能/板块判。
- 席位层目前只匹配 `EXPLANATION / EXPLAIN` 文本，**没有拉买入前五明细** ⇒ 「≥2 家关联席位且金额相近」这条**尚未自动实现**，需人工看龙虎榜确认。
- 一线天用「开盘 → 首次封板」段的最大回撤近似，一字板（开盘即封）无拉升段 ⇒ 显示「一字板」。
- 长假前最后一个交易日的首板：敢封板要承担休市跳空风险 ⇒ 通常不是纯接力盘。
