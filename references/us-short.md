## ① 流程（顺序固定）

1. **先证伪宏观叙事**（债收益率 / PMI / 加息概率 / 板块宽度），叙事站不住就不做空。9/23 实证：10Y 触 5.133%（2007-07 以来最高）、10 月加息概率 53%→66~75%、费半 30 只成分股 24 只飘绿 ⇒ 前提成立。注意 VIX 低（15.24）= 估值压制型回调，不是恐慌，别按崩盘打法做。
2. **位置判别：回踩 ≠ 破位**。三票全站 MA10 上方（MU 连 MA5 都没破）= 强势股回吐，做空逆着还在的上行结构 ⇒ 只等反抽、禁开盘追跌。
3. **跑 `us_short.py`** 拿空点候选 / 止损锚 / RR 临界表 / ETF 换算。
4. **仓位**：`us_risk_pct`（1.5%）预算；**止损出局后同板块反手 → 风险减半**（MRVL→SNDK 形态）。

## ② 多空转换地图（2026-09-24 老罗追加：「压力位/超买做空，支撑位平空，站稳支撑反多」）

> **2026-09-24 抽出为独立模块 `levels.py`**（压力位/支撑位/RSI 超买超卖，市场无关）——A 股 T0 / 缩量回调模式同样可调：`python levels.py 300404`（A股）/ `python levels.py SNDK --us`（美股）；其他模块 `from levels import levels_from_bars, resistance_levels, support_levels, rsi_stance, flex_map`。us_short.py 里 re-export 保持旧名可用。判据细则本节不变，A 股美股同一套。

脚本每次输出**多空转换地图**（无需开关）：

- **▲ 压力位**（近→远）：MA5/10/20/50、昨高、20日高、60日高中在现价上方的档位 → **做空参考**：反抽到位 + 站不上 + 缩量才空。（注：做空主触发已改裸K结构位，见第 ④ 节；此处为辅助参考）
- **▼ 支撑位**（近→远）：上述水平位中在现价下方的档位 → **平空参考**：持空单到该位主动减/平；**收盘站稳 → 反多候选**（需 rule123 买法确认，遵守「均线之上才做多」）。
- **RSI14（Wilder）**：**仅展示，不作否决依据（2026-10-10 老罗定）**。≤30 超卖**不是禁空理由** —— 强趋势下跌中 RSI 会**钝化**（一直超卖一直跌），据此禁空等于系统性错过主跌段。能否空只看结构破位 + RR + 止损距离。
- **转换规则一律以收盘确认**：盘中触碰不算数；支撑贴现价 <0.25×ATR（噪声带）标「需两日收盘确认」；反多不接下跌中的刀。

## ③ 核心判据（全部来自 9/24 实战，止损锚 S / 目标 T1 固定的纯数学）

- **RR 临界入场价**：`min_entry(RR) = (RR×S + T1) / (1 + RR)`。五档与做多同一套：R≥3 强烈推荐、2≤R<3 推荐、1.5≤R<2 合格、R<1.5 不推荐、价格到止损放弃。前三档做，后两档不做。SNDK 定稿例：S=1807、T1=1680.53 ⇒ RR1.5 ⇔ 入场 ≥ 1756.41（合格线）、RR3.0 ⇔ 1775.38（强烈推荐）。**低于合格线 = 不推荐，禁开空。**
- **入场越低 RR 单调递减**：1775→2.97 / 1758→1.59 / 1740→0.88 / 1700→0.18。追跌每一分钱都从赔率里扣；同风险下收益腰斩（回抽 1775 入场 223 股赚 $224 vs 1758 追入 144 股赚 $118）。
- **假赔率识别**：止损距离 < 0.25×ATR 的档位（如昨低 1803.67 / 止损 1805 = RR 92）是噪声带陷阱，毛刺必扫。脚本已自动打 `⚠ 噪声带` 标。
- **踏空成本 = 0**；追入被反抽扫掉 = 真钱 + 被扫完看着继续跌。一路不反抽 ⇒ 当天不做。

## ⑤ 纪律四条

1. **只做一个**（见相关性陷阱）。
2. **必须等反抽到空点**，客观标准 = 价格回到空点区 + 反抽段缩量 + 站不上空点。开盘价已低于空点 ⇒ 等回抽，不回抽就不做。
3. **止损后同板块反手，风险减半**（1.5% → 0.75%）：止损出局当天反手开新仓是标准报复性交易形态，减半不是惩罚，是留余量。
4. **2 倍 ETF 睡觉之前无论盈亏都平仓**，不拿过半夜（衰减从隔夜起算）。正股可以拿着睡觉，起来后在盘后确认是否打到止损，再处理。跌破门槛线的单边下杀不打（事件驱动暴跌随时 V 反）。

## ⑧ 存储三兄弟做空标的筛选准则（2026-10-13 老罗定）

> 三兄弟 = SKHY（SK Hynix）/ SNDK（闪迪）/ MU（美光），同属存储子板块、相关性 >0.9（见 ④ 相关性陷阱），同一判断只选一只工具做（纪律 ⑤-1）。本准则解决"三选一选谁"。

- **夜盘 / 盘前盘后做空 → 优先 SKHY**：夜盘流动性薄、反抽结构更难成型，集中做弹性最大、空点最干净的一只（SKHY），不分散到多只。
- **盘中做空 → SKHY / SNDK 二选一，看当时谁的反抽空点更优**：两者都给反抽时，挑 RR 临界入场价更优、空点结构更清晰的那只，不固定死某只。
- **尽量不空 MU**：MU 同板块里通常跌得最少（相对抗跌；us_short.py 权衡注释也印证——MU 首次触及进场易被反抽扫掉、赔率最差），做空赔率最差 ⇒ 除非 MU 自身出现独立破位 / 利空，否则不把它作为做空首选。
