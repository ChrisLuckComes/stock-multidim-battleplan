# 美股日内做空（us_short.py 打法）· 2026-09-24 SNDK 实战定稿

> **何时用**：用户要做空美股个股/板块（通常经反向 ETF 进场），或问「能不能空 / 空点止损目标」。
> **命令**：`python us_short.py SNDK`（结构+空点+临界价表+ETF 换算）；已持仓加 `--entry 1761 --stop 1805`（出本笔核算，股数按 ETF 腿）。
> **指标只走引擎口径**：`rule123.atr14`（Wilder）/ `rule123.sma`。9/24 实战教训：手算简单均值 ATR 106.42 vs 引擎 Wilder 116.50，止损锚差 9.5% —— 手算口径已废弃。

## ① 流程（顺序固定）

1. **先证伪宏观叙事**（债收益率 / PMI / 加息概率 / 板块宽度），叙事站不住就不做空。9/23 实证：10Y 触 5.133%（2007-07 以来最高）、10 月加息概率 53%→66~75%、费半 30 只成分股 24 只飘绿 ⇒ 前提成立。注意 VIX 低（15.24）= 估值压制型回调，不是恐慌，别按崩盘打法做。
2. **位置判别：回踩 ≠ 破位**。三票全站 MA10 上方（MU 连 MA5 都没破）= 强势股回吐，做空逆着还在的上行结构 ⇒ 只等反抽、禁开盘追跌。
3. **跑 `us_short.py`** 拿空点候选 / 止损锚 / RR 临界表 / ETF 换算。
4. **仓位**：`us_risk_pct`（1.5%）预算；**止损出局后同板块反手 → 风险减半**（MRVL→SNDK 形态）。

## ② 核心判据（全部来自 9/24 实战，止损锚 S / 目标 T1 固定的纯数学）

- **RR 临界入场价**：`min_entry(RR) = (RR×S + T1) / (1 + RR)`。SNDK 定稿例：S=1807、T1=1680.53 ⇒ RR1.5 ⇔ 入场 ≥ 1756.41（门槛线）、RR3.0 ⇔ 1775.38（≈MA5 空点）。**低于门槛线 = 负期望区，禁开空。**
- **入场越低 RR 单调递减**：1775→2.97 / 1758→1.59 / 1740→0.88 / 1700→0.18。追跌每一分钱都从赔率里扣；同风险下收益腰斩（回抽 1775 入场 223 股赚 $224 vs 1758 追入 144 股赚 $118）。
- **假赔率识别**：止损距离 < 0.25×ATR 的档位（如昨低 1803.67 / 止损 1805 = RR 92）是噪声带陷阱，毛刺必扫。脚本已自动打 `⚠ 噪声带` 标。
- **踏空成本 = 0**；追入被反抽扫掉 = 真钱 + 被扫完看着继续跌。一路不反抽 ⇒ 当天不做。

## ④ 纪律四条

1. **只做一个**（见相关性陷阱）。
2. **必须等反抽到空点**，客观标准 = 价格回到空点区 + 反抽段缩量 + 站不上空点。开盘价已低于空点 ⇒ 等回抽，不回抽就不做。
3. **止损后同板块反手，风险减半**（1.5% → 0.75%）：止损出局当天反手开新仓是标准报复性交易形态，减半不是惩罚，是留余量。
4. **日内收盘平**；跌破门槛线的单边下杀不打（事件驱动暴跌随时 V 反）。
