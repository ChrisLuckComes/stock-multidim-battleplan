**★★ 重复信号：「一次成功不了得来几次」—— 联想集团 00992.HK 双案例（2026-09-20）**

**这是目前最重要的样本**：同一条规则、同一只票、相隔 15 个交易日给出**两次**信号，
第一次被扫、第二次吃到整段主升浪。

| | 第一次 07-09 | 第二次 07-31 |
|---|---|---|
| D0 收盘 | 24.040（+7.71%） | 23.860（+9.75%） |
| mode | `downtrend_tl_break` | `ma_reclaim_break` |
| 平台度 | 84% | **96%** |
| 触发 / 止损 | 24.30 / 23.27（实体中点） | 24.32 / 23.68（实体中点） |
| 计划风险（距 D0 收盘） | 4.24% | 2.63% |
| **D1 跳空** | **+8.82%**（开 26.160） | **+0.08%**（开 23.880） |
| **实际入场** | **26.160**（跳空后用开盘价） | **24.320**（挂触发价成交） |
| **止损距入场 = 1R** | **11.05%**（4.20×） | **2.63%** |
| D1 日内最大回撤 | −6.57% | −1.34% |
| **结果** | **−1.00R**（07-13 被扫） | **+12.22R**（峰值 +18.50R，含 08-13 +20.18%） |

**★ 机制：跳空把入场价推高，止损线却不动。**
两次的触发价（24.30/24.32）与止损锚（都是实体中点）几乎一样，差别**全在 D1 怎么开盘**：
- 07-09 跳空 +8.82% → 入场被抬到 26.160 → 1R 从计划的 3.20% **被撑大到 11.05%（4.20 倍）**
  → 同一条止损线从「保险」变成「随手就被扫」；D1 当天就回撤 6.57%，07-13 顺势破位
- 07-31 平开 +0.08% → 入场就在触发价上 → 1R 保持 **2.63%**，止损线纹丝不动

**⇒ 「挂触发价等触发」永远优于「跳空后追开盘价」** —— 与浩瀚深度（17.38R vs 4.09R）
是同一个结论的再次验证。**跳空越大，这笔单越不该追。**

**★★ 执行推论（这条比案例本身更重要）：**
1. **止损被扫 ≠ 规则失效**，是「这次没成」。同一只票后续再出 T0，**照做**。
2. 前提是**每笔严格按 1R 控制仓位** —— 只有这样 −1.00R 的代价才承受得起，
   才有资格去等 +12.22R 的那一次。**单笔风险失控的话，第一次被扫就出局了，等不到第二次。**
3. 两次合计 **+11.22R**。若因第一次被扫就放弃这只票/这条规则，第二次整段拿不到。

**★ 事前唯一可见的差异（只能当人工复核项，不可写成硬闸门）**：**D0-1 的形态**
- 07-09 前面是 07-08 **+6.90%** —— **连续第二天大涨**（两天累涨 15.1% = 情绪透支），
  D1 高开 +8.82% 就是这段情绪的**最后一口气**
- 07-31 前面是 07-30 **−5.40% 且收在振幅下沿 22%** —— 刚被砸过、洗过，
  07-31 的 +9.75% 是「调整后第一根放量长阳」（反包）= **重新启动**
- ⚠ 此模式在 8 个正案例里**无一致性证据** → **不设阈值、只提示人工复核**。
  这正是此前反复确认的原则：**不为了修好一个案例去改参数**。
