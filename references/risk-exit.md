# 共用纪律、止损与目标

## 共用纪律

- **【正向·选股准入·池子构建】只找「前期未充分爆炒 + 走势良好 + 有新叙事」的标的（与下条总否决负向过滤配套，构成完整选股闭环）**：① **前期未充分爆炒**——用**动态PE（基于新增量/新预期）**衡量：未把最乐观未来业绩 price in 即未充分爆炒；近 12 月历史涨幅仅作参考、**不得单独排除**（中际旭创 300308 实证：十倍主升前曾腰斩以下，机械用「涨太多」排除会完美错过主升浪，老罗 2026-09-20 纠偏）；② **走势良好**——`rule123` regime=continuation 或结构 intact、均线多头排列、量价健康（涨放量跌缩量、非派发顶）；③ **有新叙事**——存在未被充分定价的产业催化（国产替代 / 新业务 0→1 / 技术迭代），且有真实订单或业绩托底信号、非纯题材。三者齐备才入池；入池后每日复盘**先过总否决负向过滤（爆炒透支/低PE陷阱一律否），再过六种买法**定买点。老罗 2026-09-20 总结固化。
- **【总否决·标的级·最高优先级】已爆炒、预期被严重透支的票，放弃不做（入场前先过这道，优先级高于六种买法）**：**本质=估值锚不匹配**——标的曾被爆炒，市值已把最乐观的未来业绩预期 price in 甚至透支；即便表面增长率很高，利润绝对值（数亿级）也配不上爆炒出的市值（千亿级），属「严重高估」，不参与。判定路径（任一满足即判「已爆炒」）：① 回看 6–12 个月出现过数倍级单边主升浪（近 12 月最大单波 ≥ +100% 且陡峭无回调），现处爆炒后修复/博弈段（现价距该顶回撤 <50%，或现价 ≥ 前高 70%、上方全是套牢盘即「第二浪修复中段」）；② 爆炒期市值相对当时/预期利润明显透支（如宏和 603256 市值曾爆炒至千亿、年化利润仅数亿，最乐观业绩也匹配不上）。③ **低PE陷阱 / 盈利质量差（反向的估值锚不匹配，假便宜）**：表面动态PE低、增长率看似高，但利润本质是周期顶点的一次性利润（囤货涨价 / 周期套利），业务无真技术壁垒与定价权（如存储模组厂，颗粒依赖海外原厂、吃涨价利差；对照真原厂「三海美闪」=三星/海力士/美光/闪迪，有产能与定价权、能平滑周期），周期拐点利润成倍回吐、经营现金流差甚至为负。市场给低PE正是用「盈利顶点对应估值低点」定价，非价值洼地——杀估值阶段直接暴跌，不参与。识别锚：业务是「原厂 / 真技术壁垒」还是「模组 / 贸易 / 周期套利」，后者即便低PE也**看都不要看一眼**，随它后面怎么折腾。满足②或③即**直接放弃 / 降为 wait**（①仅作辅助参考，不与②③叠加为否决），即便 `rule123` 给出可买 `mode`（如 continuation / T0 均线收复+过昨高）也不执行——价上看是套牢盘压制再涨空间，根上是预期已透支、再走主升基本不可能。**唯一例外**：放量**有效突破前高**（站上前高且收盘确认、量 ≥ VMA20×1.2）才视为新主升确认，可从 wait 转可观察/建仓；突破前不碰。与「强共振后不接一致预期」「T0 跳空追买看盈亏比」正交（那两条管板块/买点节奏，这条管标的本身历史与估值锚）。实证：海星 603115（2026-09-20 老罗否决：PE109x + 已走完 +313% 主升 + 现 93.68=前高71%、上方40.8%套牢区 → 放弃）；宏和 603256（市值曾爆炒至千亿、利润数亿，最乐观业绩也配不上市值 → 不做，老罗 2026-09-20 补）。
- **【估值锚量化计算流程·总否决②的可操作落地】判定「动态PE是否严重透支」必须算账，不靠感觉**：① 取未来业绩基准——优先用研报一致预期（次年/2027E 为主锚），无一致预期则自行预判（基于新增订单/新业务 0→1/产能释放曲线推次年利润）；**不过度外推 2–3 年后的乐观情景来合理化当前高价**（老罗 2026-09-20 定：看明年就行，远期故事不能用来壮胆）；**卖方研报只作 hypothesis，须用财报/IR/官方口径三方交叉验证才能定调，未验证前不写「低估/透支」确定性结论（老罗 2026-09-20 定：卖方天然单边）**；② 算动态PE = 当前市值 ÷ 次年业绩，对比**半导体设备ETF/板块估值水位**（用板块成分股TTM PE中位数作锚，2026-09实测约74x：龙头中微60x为水位下沿、华海清科116x为上沿；非龙头个股不与纯设备龙头直接对标、用ETF整体水位更客观，老罗2026-09-20定）；个股用动态PE（次年）相对水位判断——动态PE显著低于水位=相对低估（增速快）、显著高于水位且已price in最乐观=严重透支；**非纯赛道股（双主业/转型中）须分部估值（SOTP）**：各业务按各自赛道PE水位锚定后加总，不能整体套单一赛道水位——否则会被低PE传统业务拉低整体PE、误判「低估」（老罗2026-09-20定：英杰非纯半导体设备、应分开估值）；亏损无PE锚的高市值票（如中科飞测688361，亏损+1360亿市值纯预期定价）=无估值锚、风险极高、直接判谨慎）；③ 反推涨幅空间——**以短期可见未来（次年一致预期）为主锚**，合理市值 = 次年业绩 × 合理PE中枢，涨幅空间 = 合理市值÷当前市值 − 1。若现价动态PE（按次年）已 ≥ 合理区间上沿、反推涨幅 ≈ 0（当前市值已把次年预期 price in）= 短期无安全垫、只有远期故事撑——这种票「心里有数」但也最易被远期叙事套住，参与只能「逢低」等回踩给垫；若现价动态PE（按次年）已 >> 合理上沿、反推涨幅 < 0 = 严重透支、命中总否决②。实证（老罗 2026-09-20 算账范例·SOTP分部估值）：英杰电气 300820——**非纯半导体设备（工业电源+半导体双主业），须分部估值不能整体套水位**。TTM PE 82.2x已高于板块水位74x（整体口径略高估）；动态PE - **赔率优先于形态信仰**：先回答知错位 / 错亏多少 / 对了赚多少；标准突破与前移买点按「赔率与买点前移」节切换，不把某一种买点当唯一正确答案（尤其 A 股 T+1）。
- **尾盘确认**：突破与回踩都以收盘为准（A 股契合 T+1）。盘中尖刺不追。
- **不追高**：离买位 >2×ATR 不买。大阳当日不追。不追的是尖刺和延伸，不是「趋势不能买」。
- **强共振后不接一致预期（T0 级买法专属，连涨走满只观察不买）**：同板块多只核心票（≥5 只）近期同步上涨、板块 β 共振强，只作「信号有板块背书」的加分项，不代表此刻能追。**连涨 ≥3 天且累计涨幅走满**（现价相对 MA20 溢出 >10% / 距目标墙 <3%）的票，追高即接板块一致预期——止损锚不动、入场价远离 K 把 1R 撑大、潜在亏损幅度涨、盈亏比塌 → 这类票**只加自选观察、不买**；正确动作是等**温和调整**：回踩不破结构位（大阳中点 / 活平台沿 / MA5）且缩量企稳，才转为买点。与「不追高」同源：管的是「别在一致预期最满时接盘」。实例：富瀚微 300613 与星宸 301536 同属安防SoC 强共振，富瀚微连涨 +18.89%、距 MA20 溢出 +10.7%、距墙 2.13% → 降级只观察，回踩实体中点 78.32 附近企稳再评估（2026-09-20 记）。
- **T0 跳空追买看盈亏比（T0 级买法专属）**：T0 次日开盘已在 K（昨高）之上（跳空）→ 可以用开盘价追，但**必须先算盈亏比**：入场价 = 开盘价，止损锚不动，1R = 开盘价 − 止损。**已远离均线（距 MA20 溢出 >10%）或连涨走满（累计涨幅过大）的票，跳空后 1R 被撑大、盈亏比塌 → 撤单不追**；乖离率／涨幅尚合理、RR 仍达标的小跳空可接。与「强共振后不接一致预期」同源：管的是「别在一致预期最满 + 价格已远离结构位时接盘」（2026-09-20 订，替代原先「跳空即撤不追」的一刀切口径）。
- **缩量**：**回踩类**（沿线回踩 / 大阳后缩量回踩）要缩量；放量滞涨或缩量「站回」= 假确认（MDB 8-21 类）。**突破类不看量能**（2026-09-17 起）：下降趋势线家族与平台/W底**一律按价格确认** `price_conf`（收盘上半区 + 不低于前收），量能只作加分标注（非放量 → 半仓/试错仓）。
- **低开 ≠ 低吸**：跳空低开只是「便宜」，不是「回踩到位」——它本身是弱势信号。低吸必须同时满足：① 有企稳证据（缩量 / 长下影 / 收回关键位），② 买入价落在买区内，③ 买入价 **> 硬止损**。买在硬止损之下 = 开仓即止损，再便宜也不做。反例：兆龙互连 300913 2026-09-17 开 42.80（低开 −2.1%），买区下沿 43.32、硬止损 43.19，三条全不满足，开盘首根买入当日即 −4%。
- **止损**：两层必须同时写出具体价，禁止合成一个价。结构止损=收盘破才走；硬止损=盘中破则走（定价与触发见「硬止损怎么定」）。结构位：平台突破在突破位下；W底在颈线下；旗形在旗面趋势线下；沿线回踩默认 **MA5**（入场前写死，不用 MA10 除非计划另声明）；下降趋势线突破在该趋势线下；大阳后缩量回踩在大阳低点下（一字板在缺口下沿/前收下）。禁止整数关/心理位。逻辑止损：催化证伪、板块转弱、龙头负反馈。时间止损：短线 5–10 个交易日未验证则降仓。
- **Conviction vs Swing**：用户说「好生意/核心名/信早信」→ 可付溢价提前买，但仍要小仓 + invalidation。用户说「技术/回踩/不追高」→ 严格按六种模式。禁止一把梭。

`rule123.py` 辅助字段：`regime`（continuation / reversal / mixed）只描述位置，**不单独否决**。HH 两两比较只当备注。不用 MA60。

## 硬止损怎么定

结构止损管假跌破，硬止损管中大阴/跳空。计划卡两档都要有价。入场前必须写死：**结构锚** + **硬止损锚（三选一）** + **硬止损价**；破了禁止换锚、禁止改宽。

**结构止损**：收盘破才走。盘中刺穿、尾盘收回，不走。沿线回踩的结构锚是**回踩的那条线本身**（2026-09-18 修正，见下「铁律零」）。

**硬止损锚（三选一，入场前选定）**：

| 锚 | 怎么取 | 默认用于 |
|---|---|---|
| **MA5** | 计划当日的 MA5 价（写死数字；之后均线挪了也不改硬止损） | 沿线回踩 |
| **阳线下沿** | 入场相关那根阳线最低价（突破阳 / 回踩所依大阳） | 普通阳线突破、大阳后回踩 |
| **大阳线中点** | **(最高价+最低价)/2** | 很长的大阳（实体或振幅明显偏大，约 ≥0.8×ATR 或涨幅 ≥3%）；**平台/W底/旗形突破单若突破日是这种长阳，也用中点**，不用沿下贴毛刺 |

**硬止损定价（必须有 gap）**：

- 硬止损 = 选定锚再下 **0.10–0.15×ATR**，默认 **0.10**。**禁止把硬止损写成锚本身**（贴锚会被探底针扫掉）。
- gap 不是另找更深支撑，也不是按成本改宽。
- **锚名与数值必须绑定**：计划卡写出的锚名（MA5 / 阳线下沿 / 大阳中点 / 缺口下沿）必须真能算出那个价 —— `硬止损 = 该锚价 − 0.10×ATR`。**禁止为迁就买区把数值悄悄下移、却保留锚名**：那会印出「锚=大阳中点」配一个离中点好几个 ATR 的价，比没有锚更危险。
- **锚与买区冲突时，让路的是买区**：若 SKILL 的合法锚算出的硬止损都落在买区下沿之上（成交即已破止损），就把**买区下沿抬到硬止损之上**并标 `stop_warning`，可执行价位以 `primary_lo` 为准。不许改锚名、不许下移止损数值、不许靠「再等等」绕过。
- **该修正必须落到报告里**：`stop_plan` 靠修改传进来的 `z` 来完成上抬。若调用方只传 `dict(z)` 副本，修正会被吃掉 —— 报告仍印「买区未上抬 + 硬止损落在买区之内」，并据此打出虚高盈亏比。实测（601233 2026-09-01）：挂单 26.89、硬止损 26.84 落在买区 25.52–26.89 **之内**，报告写成 **24.20:1**，修好后是 **1.52:1**。所以：修正必须**回写真实 `z`**，且 `room_and_cap` 要在打印买区**之前**调用。
- 例：锚=阳线下沿 174.84、ATR≈8.8 → 硬止损 174.84−0.10×ATR≈174.0。长阳高 22.45 / 低 20.90 → 中点 21.675，ATR 1.42 → 硬止损 ≈21.53（比「沿 22.10−0.10×ATR」宽，抗洗）。

**铁律零：任何止损锚都必须低于现价（2026-09-18 SNDK）**

锚价 ≥ 现价 = 买入的那一刻就已经在止损之下（**买入即止损**）。这不是"宽一点/紧一点"的问题，是这个锚根本不可用 —— 必须先剔除，再谈上面那些取舍；剔除后无处可去的如实不给止损，**绝不靠抬买区去迁就**。

- 触发场景：**价格急跌、均线滞后**。SNDK 2026-09-14~09-16 从 1764 一路跌到 1519，MA5 依次还在 1676 / 1634 / 1586，全都**高过当日收盘**。旧代码在 `anchor=hl_trendline` 时把结构止损换成 MA5，于是「收盘破 MA5」在买入那一刻就已成立；`stop_plan` 接着按铁律二把买区抬到硬止损之上，输出的买区 **1580.16–1604.72 整个在收盘 1519.97 之上**，而 `recommend` 仍是 True；结构止损 1585.76 还高过次日开盘 1564.53。
- **沿线回踩的结构止损 = 回踩的那条线本身**（回踩单的定义就是"回踩到这条线买、收盘破这条线走"），不再用滞后的 MA5 顶替；MA5 只在该线已不可用（价格跌到线下）时作备选，且同样须过铁律零。
- **出口总闸门**：`attach_stops_targets` 在给出结论前再拦一道 —— `recommend=True` 必须自带一个真正位于现价之下的止损，否则撤销整单并标 `stop_above_price`、verdict 写「止损锚在现价之上·买入即止损·不接」。同类错误已出现过三次（INTC 昨收口径、赛分盈亏比压穿突破位、BE 陡线外推），共同点是**锚点逻辑正确 ≠ 锚点数值可用**，单点补锚总会漏下一个，所以必须有总闸门。
- **沿线回踩的买区**：下沿 = 线 −0.05×ATR（只留毛刺），上沿 = 线 +1.0×ATR（与贴线门槛同源）。旧版是「线 ±1.0×ATR」双侧对称，下沿落在**破线之后**的区域，且必然低于任何「锚 −0.10×ATR」的硬止损 → 每次都触发铁律二的抬买区分支，上面的荒谬买区就是这么来的。

**硬止损必须在噪声带之外（2026-09-18，只对突破类成立）**：

硬止损距**买区下沿**不足 **0.25×ATR** 时，等于把止损塞进单日噪声带 —— 名义上有止损，实际一次正常波动就被扫。此时若同族还有**更宽的合法锚**（大阳中点 → 阳线下沿），降级到更宽那条并在 `hard_note` 里留痕；同族没有更宽锚时**不许硬凑宽度**，但必须标 `hard_noise=true` 如实提示。

**口径只适用突破类**（`BREAKOUT_MODES` = 平台突破 / W底 / 旗形 / 下降趋势线）。理由是可执行价不同：突破类的买区下沿**就是突破位本身**，是真实成交价；回踩类（沿线回踩 / 大阳后缩量回踩）买在**线上**，买区下沿只是理想价，主风控是**收盘破线**的结构止损，硬止损本就是 0.10×ATR 的毛刺滤网。拿突破类阈值去量回踩类，2026-09-18 全市场样本 44 个候选里误报 15 个（全是 `line_pullback`）—— 警告一旦三成命中就退化成噪声，没人再看。回踩类只报 `hard_dist_atr`，不报 `hard_noise`。

- 触发场景：**突破后隔夜/次日入场**。买区已随突破上移，而 `bars[-1]`（突破根）中点算出的止损离沿极近。
- 实证 INTC 2026-09-17 盘中：买区 107.57–113.53、ATR 5.96。大阳中点 107.92 − gap = **107.32**，距买区下沿仅 **0.04×ATR**（当日振幅 1.05×ATR，比噪声还窄）。换锚到阳线下沿 → 硬止损 **104.10**（距沿 0.58×ATR、距现价 1.17×ATR）。
- 换锚不违反铁律一/二：数值仍恒 = 该锚价 − gap、仍落在买区下沿之下，**只是不选那条塞在噪声带里的锚**。破了之后禁止再换锚改宽（这条不变）。

**硬止损触发（写进计划卡，盘中不发明）**：

- 开盘价已在硬止损下：开盘走，不等。
- 盘中成交价跌破后，**3 分钟仍在下面，或分钟线继续新低**：市价走，不挂死限价等反抽。
- 跌破后下一两分钟立刻收回硬止损之上，且不是放量加速阴：当毛刺，不卖。
- 等 3 分钟只防单根毛刺，不能替代 gap，也不能理解成「等等看会不会探底回升」。

**禁止**：按成本改宽；硬止损已被刺穿后再换到另一个更宽的锚（例如从沿改 MA5、再改中点）；用「这只股爱探底回升」取消硬止损。要吃探底回升就只守结构止损（收盘破），两套不要混用。

**两档止损的执行口径（能不能睡着觉就靠这条）**：

两档的可执行性完全不同，输出里必须各带口径（字段 `struct_exec` / `hard_exec`）：

| 腿 | 口径 | 需要什么 |
|---|---|---|
| 结构止损（`struct`） | **收盘口径** | **不用盯盘**：次日开盘 / 晨起按收盘价判定，收盘破即走 |
| 硬止损（`hard`） | **盘中口径** | 需要**盯盘**，或券商支持条件单/止损单；**两者都没有时此腿不可执行** |

- 已知约束：**不能盯整场 + 券商不支持挂止损单** → 睡眠时段的「硬止损腿」形同虚设，保护只剩收盘轨。
- 所以不能盯盘时**不要指望硬止损**，用两个替代：
  1. **用买价替代止损**：限价压到突破位附近（≤ 突破位 + 0.5×ATR）。买在沿上，跌回沿下就是失败，风险天然只有 ~0.5–1.0×ATR，不需要任何盘中动作。
  2. **用仓位替代止损**：无盘中保护的隔夜仓，风险按「没有止损」估（大票隔夜跳空尾部约 1.5–2 倍于正常止损幅度）→ **仓位减半**。
- 反向禁令：**不许把「等次日开盘再处理」当日常止损纪律** —— 那是无保护持仓，只能作例外（临时无法盯盘），且必须同时下调仓位。风控上没有免费的睡眠。
- 注：`room_and_cap` 的买入上限 `P_max` 与仓位股数都建立在硬止损上，换锚变宽会自动压低 `P_max`、减少股数 —— 这是正确联动，不是输出变保守。

## 目标价（止盈档：目标1 / 目标2）

必须能回答「什么价卖、卖多少、止损移到哪」。

- **目标1**：较近阻力（次级前高、测量涨幅、通道上沿、估值中枢）。
- **目标2**：更高阻力（ATH / 平台测量 / 乐观催化）。
- 达目标1 减 1/3～1/2，止损上移到成本或沿用的那条线；达目标2 再减一半，剩余移动止损。
- 下降趋势线突破（T2）未过前高时，目标1 先看平台沿/R1。
- 催化证伪或放量破位：不等目标，直接走。

## 作战计划卡（首屏并列：入场 / 止损 / 目标）

> ★★ **首屏第一行 = 最高盈亏比路径（强制）**：本卡必须先给「R 最高 且 每股风险 ≥0.25×ATR」的那一条，用独立高亮卡写全 买入价 / 止损 / 每股风险 / 仓位股数 / 到各目标 R / 需回落幅度；其余档位按 R 降序排其后。**「追突破」档若非最高 R，同行必须标「赔率偏弱·不建议」。** 不许只给引擎单条路径就交差（做法见 entry-odds.md 的「Agent 强制决策」第 7 条）。

0. **模式卡**：`mode` / `priority` / `verdict`。按当日唯一模式写。`wait` 只写预案。若存在「标准突破 vs 前移买点」两条路径，用一句话写清**优先哪条及赔率理由**。
1. **入场**：价来自 `buy_zone`（`plan_entry` 计算），禁止硬编码均线底座（石头科技 106–116 那种深 MA 区）。图上标 `anchor`+`level`、R1、止损、目标1/目标2。
2. **分仓**：试错 10–20% → 确认 +20–30% → 加仓 +20–30%。T2 默认停在试错仓，直到升级为 T1。
3. **止损**：结构止损 + 硬止损两档都写价，见「硬止损怎么定」。必须能回答：**在哪里知错、错了亏多少**。
4. **目标1 / 目标2 + 减仓节奏**。必须能回答：**对了能赚多少**（相对硬止损风险的约略 R）。
5. **失效条件**。
6. **高β / 大盘板块资金**是否允许执行。
7. **扫雷结论**：解禁 / 减持 / 立案调查等（有则一句话+日期；无则写「近窗无重大解禁减持立案」）。有雷且窗口临近时，即使 `mode` 可买也降级为 wait 或试错仓上限。
8. **双轨打分**：投资价值 x/10 + 短线博弈 y/10，各附一句理由（见「强制双轨打分」）。供用户综合评判仓位与是否值得拿；Agent 不得省略。
9. **龙头轻量对照**：主线概念 · 龙头 1–3 只及理由 · 近期相对强度与趋势状态 · 主标的 vs 龙头优先研究谁。只有用户显式要求同行完整分析时，才补同行模式卡、扫雷、双轨分与计划。
