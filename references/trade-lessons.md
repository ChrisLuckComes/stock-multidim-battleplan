## L001 · 消息驱动型标的：禁止在开盘瞬间抢单

- **日期**：2026-09-24
- **标的**：诺诚健华 688428（科创板）
- **教训一句话**：**利好公告兑现日的开盘 1~3 分钟是价格发现阶段，散户任何单型都没有优势 —— 这类仗不该打，不是"没抢到好价"。**

### 事实

| 时点 | 事件 |
|---|---|
| 09-24 上午 | 带量砸盘，收 31.26（-6.41%），主力净流出 2,431.7 万，内盘 > 外盘 |
| 09-24 12:13 | 午间公告：与礼来合作（首付 ≤1 亿美元，里程碑 32.5 亿美元） |
| 09-24 13:00 | 市价（对手方最优）抢入，**成交 33.70**，超保护限价 31.88 达 **5.66%** |
| 09-24 13:17 | 现价 30.70（-8.08%），今高 35.00 → 自最高 **-12.4%** |
| 结果 | 200 股浮亏 **(33.70 − 30.70) × 200 = 600 元（-8.90%）** |

### 错在哪（三条，按重要性）

1. **13:00 回补这个动作本身就不该发生** —— 早盘 32.70 保本出是**对的**（带量砸盘 + 跌破结构）；13:00 因公告买回才是错的。**分界线在这里，不在"卖早了"**。这属于「后悔式回补」的加强版：**同一标的当日卖出后，不得因消息回补**。
2. **公告前的信号已经完整给出** —— 上午带量下跌 + 主力净流出 + 内盘 > 外盘 = **利好未被认可**。午后抢筹 = 接提前埋伏资金的货。信号在午休前就齐了，不需要等到 13:00 才知道。
3. **单型层面无解，不是执行失误**：
   - 市价（对手方最优）：成交价 = 报入那一刻的卖一价，**输在报入时点（秒级）**，且实际成交可能远超保护限价；
   - 预埋单 + 保护限价：**设上限则可能不成交，不设上限则价格失控** —— 二者自相矛盾，**不存在"既抢到又便宜"的解**。
   - ⇒ 把本次失败解读为"下次提前挂、挂更高价" = **把"贵 5.66%"升级成"贵 10%+"**，方向完全错。

### 可复用规则

1. **禁止在消息驱动型标的的开盘瞬间抢单**：A 股 09:30 开盘与**午间公告后的 13:00 开盘**同样适用；美股对应其开盘/盘前首分钟。
2. **正解**：等开盘后 **≥5 分钟**，第一波回落给出结构后再评估；或**完全不做**。
3. **前置识别信号（任一命中即不参与）**：公告前已带量下跌、主力净流出、内盘 > 外盘、A/H 同步上市无时间差可用。
4. 若仍要参与，只做**回落确认后的第二次结构**（有明确锚与止损），不做开盘的价格发现。
5. 与「后悔式回补禁止」合并执行：**同一标的当日卖出后，消息不构成回补理由**。
6. **午间消息先扫再决定做不做**（2026-09-24 用户定）：公告出来后、任何下单前，必须扫两件事。① **黑历史**：该股上一次同类利好当日是不是高开/冲高后放量收阴。② **利好出尽嫌疑**：公告前已经带量下跌，午后买盘只是手里有货的人兑现的窗口。任一命中，当日不做，包括 13:00。诺诚 688428 两次 BD（2025-10-09 Zenas、2026-09-24 礼来）都是兑现，不是启动。

### 补充证据：这不是孤立事件 —— 该标的的 BD 公告「有前科」

老罗 2026-09-24 指出"这股有黑历史：之前有一次出个大 BD 大高开砸绿出大阴线"。经核（通达信日线），完全属实：

| | **2025-10-09**（Zenas 授权公告后首日） | **2026-09-24**（礼来合作公告当日） |
|---|---|---|
| 前收 | 28.52 | 33.40 |
| 开盘 | **31.42 — 高开 +10.17%，且 = 全天最高价** | 33.14（低开 −0.78%） |
| 最高 | 31.42（开盘即顶） | 35.00（盘中冲高 +4.79%） |
| 最低 | 26.09 | 30.66 |
| 收盘 | **26.74（−6.24%）** | **≈30.70（−8.1%）** |
| 全日振幅 | **18.69%** | 13.0% |
| 开盘 → 收盘 | **−14.90%** | −7.4% |
| 成交量 | 281,615 手 = 前一日的 **4.47 倍** | 210,171 手 ≈ 前一日 **1.00 倍** |
| 后续 | 10-23 见 21.59 → **自公告日开盘 −31.3%**，阴跌近 1 个月 | 待观察 |

- **两次交易结构几乎复制**：都是"首付款最高 1 亿美元 + 近期里程碑 + 潜在总额 20 亿 / 32.5 亿美元"的授权许可。
- **差别在反应强度**：第一次还给了一个高开 +10.17% 的进场窗口（随后全天砸 14.9%）；第二次**连高开都没有**（低开起步、盘中冲高 35.00 后崩）。
- ⇒ **该标的的 BD 公告对二级市场是「兑现窗口」而非「启动信号」，且第二次的边际信息量明显小于第一次**（市场已学过一遍）。
- ⇒ 由此新增扫雷条目（已写入 `references/research-report.md` 扫雷第 4 类 / `SKILL.md` / `AGENTS.md`）：**买前必须回看该标的「上一次同类公告当日 K 线」——是否高开？收阴？放量几倍？有前科则公告当日禁止追入。**

### 抢跑判据：消息之前已经涨过一波 = 内幕盘已建仓（2026-09-24 老罗定）

老罗原话：「**A 股科创板创新药很多内幕盘。如果没出消息之前，已经有了一波涨幅，出消息了就是要收割的时候。**」

**适用范围（不限于，但最典型）**：**科创板创新药 / Biotech 的 BD 类公告**（license-out 授权、对外合作、里程碑交易、重磅临床数据）。理由：一笔 BD 从接触到签约通常跨数周到数月，环节上涉及对方 BD 团队、CRO、财务顾问、律所 → **信息几乎必然提前扩散**，等公告落地时股价已含该预期。**公告日对埋伏盘是兑现窗口，不是启动信号。**

**强制判据（下单前必须先算，脚本 `python pre_runup.py <code> --date <公告日> [--bench <板块指数>]`）**：

| 判据 | 阈值 | 动作 |
|---|---|---|
| ★★★ **强抢跑** | 公告前 **5 日 ≥ 10%** 或 **10 日 ≥ 15%** | **公告日禁止追入**（含午间公告后的 13:00） |
| ★★☆ **中度抢跑** | 公告前 5 日 ≥ 6% 或 10 日 ≥ 10% | 只做公告后 ≥5 分钟的**第二结构**，仓位减半 |
| ★☆☆ 未见显著抢跑 | 低于以上 | 仍须叠加「利好公告反应史」检查（第 4 类） |

叠加检查：**个股同期涨幅 vs 板块/同行基期涨幅**。**个股独涨 >> 基准 ⇒ 内幕盘特征更显著**；板块同步走强 ⇒ 更像行业性行情，判据可打折但不可豁免。

**诺诚健华 688428 实测（`pre_runup.py`，新浪不复权日线，基准日 2026-09-23 收 33.40）**：

| 指标 | 数值 |
|---|---|
| 公告前 5 日涨幅 | **+16.09%** |
| 公告前 10 日涨幅 | **+15.61%** |
| 公告前 20 日涨幅 | **+18.65%** |
| 距 20 日低点（25.84） | **+29.26%** |
| 判定 | **★★★ 强抢跑 —— 消息已被充分定价，公告日禁止追入** |

⇒ 事后完全对得上：13:00 你接到的那批货，正是 9 月中下旬这段 +29% 涨幅的埋伏盘在兑现。**判据在 09-23 收盘就已经能给出来，不需要等公告。**

**这条判据为什么比「利好公告反应史」更前置**：反应史要等"上一次公告"做样本（可能没有）；**抢跑涨幅每只票每天都能算，是唯一一个在公告发生当晚就能给出结论、且不需要历史样本的否决型指标。**

### 尾部风险：T+1 把「止损」这条安全带拆了（本条的真正重点）

⚠️ **不许把这笔的亏损说成"就 600 块、几百元而已"。** 600 元只是当日 13:27 的**中途浮亏**，不是这笔仓位的最大亏损。原因：**当日买入的 200 股 T+1 才能卖**，所以这笔仓位在买入后的第一个交易日**没有任何可行的止损动作**（含科创板盘后固定价格交易 15:05–15:30，同样受 T+1 约束）——

> **消息驱动型 + T+1 的组合下，单笔亏损不由"我设的止损位"决定，而由"买入后两个交易日的累计跌幅"决定。**

以成本 **33.70 × 200 = 6,740 元**为基数（跌停价按科创板 20% 计：33.40 × 0.8 = **26.72**）：

| 情景 | 价格 | 浮亏 | 相对成本 | 占主力池 5 万 |
|---|---|---|---|---|
| 09-24 13:27 现价 | 30.74 | **−592** | −8.78% | −1.18% |
| 09-24 收在**跌停** | 26.72 | **−1,396** | −20.71% | −2.79% |
| 09-25 低开 −3% | 25.92 | −1,556 | −23.09% | −3.11% |
| 09-25 低开 −5% | 25.38 | **−1,664** | **−24.69%** | **−3.33%** |
| 09-25 低开 −8% | 24.58 | −1,824 | −27.06% | −3.65% |
| 09-25 再跌停（极端） | 21.38 | **−2,465** | −36.56% | −4.93% |

- **老罗的口径成立**：今日跌停 + 次日低开 −5% ⇒ 亏 **−24.7% ≈ −1,664 元 = 主力池的 3.33%**，是**单笔风险预算 1.5% 的 2.2 倍**。
- **修正一句旧结论**：「200 股最小申报单位救了这笔」只对了一半 —— 200 股锁住的是**投放额**（6,740 元 = 主力池 13.5%），**锁不住亏损百分比**。缺了止损前置，百分比敞口该多大还是多大。
- **链路**：① 消息驱动 ⇒ 没有计划、没有预设买点、没有硬止损；② 13:00 抢入 ⇒ 成本离破位结构只有 3% 距离；③ T+1 ⇒ 破位当天动不了，全部风险过渡到次日跳空。**三个各占一环，缺一环都出不了 25%。**

### 正向启示

- 真正要记住的不是「今天浮亏 600」，而是「**这类仗根本不该打**」——按老罗最坏的算法，这笔的**名义最大亏损是 −1.7k 到 −2.5k（主力池 3.3%~4.9%）**，而买入那一刻它连一个止损位都没有。
- ⇒ **消息驱动型买入的前置硬约束（新增）**：任何因消息/公告决定参与的仓位，**下单前必须先写下硬止损价**；写不出来 = 这笔不做。因为 T+1 不给第二次机会，止损位是唯一能在下单瞬间锁死的风险上限。
- ⇒ **T+1 是这笔的放大器，不是借口**：A 股当日买入不可卖是制度事实；能规避它的只有"买之前就确定这笔最坏亏到哪"。
- 仍需保留的判断：同样的 −8.9%，若按满仓 50,000 打就是 −4,450 元（预算 3 倍）——**仓位纪律负责让错误变小，不负责让它变对**。
